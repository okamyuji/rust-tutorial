# Rustチュートリアル：経験豊富なプログラマーのための実践ガイド

このリポジトリは、プログラミング経験が豊富な開発者向けのRustチュートリアルです。

## 構成

- `docs/` には各章のチュートリアルドキュメントがあります。
- `code/` には各章に対応するサンプルコードがあります。

## 章立て

1. 第1章：所有権システムとメモリ管理
   - 所有権の規則とメモリセーフティ
   - ムーブセマンティクスとCopy/Cloneトレイト
   - 借用チェッカーの動作原理
   - 内部可変性パターン（Cell、RefCell、Mutex）
   - スマートポインタ（Box、Rc、Arc）の使い分け
2. 第2章：ライフタイムの深層理解
   - ライフタイム注釈と省略規則
   - 高階トレイト境界（HRTB）と変性（variance）
   - `'static`ライフタイムの意味
3. 第3章：トレイトシステムの高度な活用
   - トレイトオブジェクトとオブジェクト安全性
   - 関連型とジェネリックパラメータの使い分け
   - コヒーレンスルール、孤児ルール、特殊化のパターン
4. 第4章：非同期プログラミングとFuture
   - async/awaitの内部動作と、FutureトレイトとPin
   - 非同期トレイト、タスクスポーン、エグゼキュータの選択
   - 非同期コードにおけるライフタイムとキャンセル
5. 第5章：マクロとメタプログラミング
   - 宣言的マクロ（macro_rules!）の作成と活用
   - マクロの衛生性（hygiene）とスコープ規則
   - コンパイル時計算とconst fn

## 使い方

各章のサンプルコードは、独立したCargoプロジェクトとして構成しています。

```bash
# 第1章のコードをビルド・実行
cd code/chapter01
cargo build
cargo run --bin <バイナリ名>

# テストを実行
cargo test
```

第4章の`problem5_web_scraper`はhttpbin.orgへHTTPSで接続します。`websocket_server`は終了しないサーバーなので、Ctrl+Cで止めてください。

## 必要環境

- Rust 1.98.1とCargoで動作を確認しています。
- 第4章の依存クレートはRust 1.88以上を要求します。
